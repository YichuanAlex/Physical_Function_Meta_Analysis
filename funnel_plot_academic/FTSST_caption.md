# Funnel Plot Analysis: FTSST

## Figure Description

This funnel plot assesses publication bias by plotting mean differences against their standard errors. The gray shaded area represents the expected 95% confidence interval. A symmetric funnel shape suggests minimal publication bias, while asymmetry may indicate potential bias.

## Methods

### Statistical Analysis
- **Meta-analysis model**: Random Effects Model (DerSimonian-Laird)
- **Effect measure**: Mean Difference (MD)
- **Confidence intervals**: 95%
- **Publication bias assessment**: Visual inspection of funnel plots
- **Fail-Safe N**: Rosenthal's method

### Visualization
- **Color scheme**: Colorblind-friendly palette (seaborn.colorblind)
- **Resolution**: 300 DPI
- **Format**: PNG
