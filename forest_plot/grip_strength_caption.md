# Forest Plot Analysis for grip strength

## Analysis Results

### Fixed-Effects Model Results

Summary Effect (SMD): -0.055 to 0.272

### Plot Description

The forest plot displays the standardized mean difference (SMD) for each study along with its 95% confidence interval. The diamond at the bottom represents the summary effect from the fixed-effects model.

## Methods

All analyses were performed using Python with matplotlib for visualization. Fixed-effects models were used for meta-analysis.
