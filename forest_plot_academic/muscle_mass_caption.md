# Forest Plot Analysis: Muscle mass

## Figure Description

This forest plot displays the standardized mean differences (SMD) and 95% confidence intervals for individual studies and the summary effect from a random-effects meta-analysis. Each study is represented by a horizontal line (confidence interval) and a point (effect size). The red diamond at the bottom represents the summary effect across all studies.

## Methods

### Statistical Analysis
- **Meta-analysis model**: Random Effects Model (DerSimonian-Laird)
- **Effect measure**: Standardized Mean Difference (SMD)
- **Confidence intervals**: 95%
- **Publication bias assessment**: Visual inspection of funnel plots
- **Fail-Safe N**: Rosenthal's method

### Visualization
- **Color scheme**: Colorblind-friendly palette (seaborn.colorblind)
- **Resolution**: 300 DPI
- **Format**: PNG
- **Axes**: Clear labeling with appropriate titles
- **Annotations**: Summary statistics and methodological details

## Results

Summary Effect (Standardized Mean Difference (SMD)): 0.023 to 0.416
