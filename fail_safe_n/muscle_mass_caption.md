# Fail-Safe N Analysis for Muscle mass

## Analysis Results

### Fail-Safe N Results

Fail-Safe N (Rosenthal): 1.14

The Fail-Safe N indicates the number of unpublished studies with null results that would be needed to make the combined effect statistically non-significant.

## Methods

All analyses were performed using Python with matplotlib for visualization. Fixed-effects models were used for meta-analysis.
